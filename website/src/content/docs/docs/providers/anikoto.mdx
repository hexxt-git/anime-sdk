---
title: anikoto
description: Anime playback source for anikototv.to with sub/dub and VTT subtitles via MegaPlay embeds.
---

`AnikotoSource` combines `anikototv.to` search with `anikotoapi.site` for episode metadata. Resolves streams via MegaPlay's embed API. Sub and dub, with VTT subtitle tracks.

## Capabilities

- `search`, `episodes`, `stream`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['anilist', 'anikoto'] });

const results = await sdk.search('Solo Leveling', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);

const ep = episodes.find((e) => e.languages.includes('dub')) ?? episodes[0];
const stream = await sdk.stream(ep, { language: 'dub' });
```

## Stream resolution

1. Fetch embed at `megaplay.buzz/stream/s-2/{embedId}/{language}`
2. Extract `fileId` from `<title>File XXXXX - MegaPlay</title>`
3. Fetch sources from `/stream/getSources?id={fileId}`

## Supported languages

| Language | Support                       |
| -------- | ----------------------------- |
| `'sub'`  | Full                          |
| `'dub'`  | Where available (per-episode) |
