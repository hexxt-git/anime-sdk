---
title: kitsu
description: Kitsu JSON:API catalogue source — search and info with cross-catalogue mappings.
---

`KitsuSource` queries `kitsu.io/api/edge` and returns `Media` records. Uniquely surfaces cross-catalogue mappings (AniList/MAL/AniDB/TVDB) from Kitsu's relationship graph.

## Capabilities

- `search(query, kind)` — full-text search
- `info(id)` — full `Media` record including cross-catalogue mappings

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['kitsu'] });

const results = await sdk.search('Cowboy Bebop', { kind: 'anime' });
// results[0].mappings.kitsu → 1
// results[0].mappings.mal   → 1 (when Kitsu has the mapping)
```

## Notes

- No API key required.
- `info()` includes a `?include=mappings` query that populates `media.mappings.anilist`, `media.mappings.mal`, etc.
- Kitsu doesn't expose a season enum — `media.season` is always undefined.
- Score is parsed from `averageRating` (a string like `"78.56"`) and rounded to an integer with `scale: 100`.
