`MangadexSource` uses the official `api.mangadex.org` JSON API. High-quality images, huge catalogue, reliable.

## Capabilities

- `search`, `chapters`, `pages`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['mangadex'] });

const results = await sdk.search('Frieren', { kind: 'manga' });
const { items: chapters } = await sdk.chapters(results[0]);
const pages = await sdk.pages(chapters[0]);
// pages.pages[0].url → image URL
// pages.pages[0].origin.host → 'uploads.mangadex.org'
```

## Pagination

For long manga (Berserk, One Piece, etc.), `chapters()` returns all chapters in one call by paginating through the `/manga/{id}/feed` endpoint (500 per page). Expect this to take a few seconds for 1000+ chapter manga.

## Notes

- API at `api.mangadex.org` — no authentication required for public content.
- Images served from `uploads.mangadex.org`; require `Referer: https://mangadex.org/` header.
- Page URLs are `{baseUrl}/data/{hash}/{filename}` where `baseUrl` comes from the at-home server endpoint.
