---
title: gogoanime
description: Anime playback source for anineko.to — HTML scraping with HLS stream extraction.
---

`GogoanimeSource` scrapes `anineko.to`, extracts video server buttons from episode pages, then uses `GenericHlsExtractor` to resolve direct HLS URLs. Useful fallback for titles AllManga is missing.

## Capabilities

- `search`, `episodes`, `stream`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['anilist', 'gogoanime'] });

const results = await sdk.search('One Piece', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);
const stream = await sdk.stream(episodes[0]);
// stream.isHls → true
```

## Notes

- Sub only.
- Stream resolution: scrapes `button.nv-server-btn[data-video]` from the episode page, tries each server with `GenericHlsExtractor`, stops on first success.
- Dub variants have `-dub` in the show slug — the SDK handles this automatically.
