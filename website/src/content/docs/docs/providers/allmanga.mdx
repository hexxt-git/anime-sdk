`AllmangaSource` resolves anime streams from `allmanga.to` via the AllAnime GraphQL endpoint. Supports sub, dub, and raw. Handles mp4upload embeds, wixmp packager links, and generic HLS embeds.

## Usage via SDK

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['allmanga'] });

const results = await sdk.search('Attack on Titan', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);
const stream = await sdk.stream(episodes[0], { language: 'dub' });
console.log(stream.url, stream.isHls);
```

## Supported languages

| Language | Support                   |
| -------- | ------------------------- |
| `'sub'`  | Full: most titles         |
| `'dub'`  | Full: many popular titles |
| `'raw'`  | Where available           |

## How stream resolution works

1. **Persisted GraphQL query**: fetches episode sources using a SHA-256 hash to identify the query. The response contains a `tobeparsed` field.
2. **AES-CTR decrypt**: `tobeparsed` is base64-decoded, then the nonce (bytes 1–12) and ciphertext (bytes 13 to end−16) are extracted. The key is SHA-256 of `'Xot36i3lK3:v1'`. The IV is a 16-byte nonce with a counter suffix.
3. **XOR decode**: individual source URLs starting with `--` are a hex string where each byte is XOR'd with `0x38`. After decode, `/clock` → `/clock.json`.
4. **Source dispatch**: decoded URLs are routed to the appropriate handler:
   - `/clock.json` → internal AllAnime endpoint with `links` array (wixmp or direct mp4/hls)
   - `.m3u8` or `.mp4` → used directly
   - `mp4upload.com` → `Mp4UploadExtractor`
   - anything else → `GenericHlsExtractor` as a fallback
5. **Fallback**: if the persisted query fails, a regular GraphQL POST is used.

## Notes

- Does not require HTML scraping — uses the GraphQL API only.
- The AES key phrase (`'Xot36i3lK3:v1'`) is embedded in the source and may change if AllAnime updates its API.
- `clock.json` endpoints have an 8-second timeout per `stream()` call.
