`WeebcentralSource` scrapes `weebcentral.com`. Good alternative for manga not on MangaDex or Mangapill.

## Capabilities

- `search`, `chapters`, `pages`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['weebcentral'] });

const results = await sdk.search('Frieren', { kind: 'manga' });
const { items: chapters } = await sdk.chapters(results[0]);
const pages = await sdk.pages(chapters[0]);
```

## Notes

- Uses `/search/data?text=...` endpoint which returns HTML fragments.
- Chapter list from `{seriesId}/full-chapter-list` — returns all chapters in one request.
- Pages from `chapters/{chapterId}/images?reading_style=long_strip`.
- Requires `Referer: https://google.com` and `User-Agent` headers to avoid bot protection.
