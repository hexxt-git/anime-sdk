title: megaplay
description: Anime playback source for megaplay.buzz using AniList for search and native ID mapping.
---

`MegaPlaySource` uses AniList's GraphQL endpoint for search (returning the same AniList IDs it uses natively), then resolves streams against MegaPlay's mapping endpoints. Sub and dub with VTT subtitle tracks.

## Capabilities

- `search`, `episodes`, `stream`, `mapping`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['anilist', 'megaplay'] });

const results = await sdk.search('Frieren', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);
const stream = await sdk.stream(episodes[0], { language: 'sub' });
// stream.subtitles → VTT subtitle tracks when available
```

## Native ID mapping

MegaPlay indexes its catalogue by AniList ID — `lookupByMapping({ anilist: 154587 })` immediately returns `'154587'` without a fuzzy search. This makes cross-source resolution instant when the metadata record includes an AniList ID.

## Stream resolution

1. Fetch the embed page at `megaplay.buzz/stream/ani/{anilistId}/{epNum}/{language}`
2. Extract the `fileId` from `<title>File XXXXX - MegaPlay</title>`
3. Fetch sources from `/stream/getSources?id={fileId}`
4. Return the `sources.file` URL

## Supported languages

| Language | Support                |
| -------- | ---------------------- |
| `'sub'`  | Full                   |
| `'dub'`  | Full (where available) |
