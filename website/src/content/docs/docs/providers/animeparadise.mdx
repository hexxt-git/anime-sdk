---
title: animeparadise
description: Anime playback source for animeparadise.moe with external VTT subtitle tracks.
---

`AnimeParadiseSource` uses the `api.animeparadise.moe` REST API. The best option when you need **external subtitle tracks** — the VTT URLs are served separately and can be passed directly to `<track>` elements.

## Capabilities

- `search`, `episodes`, `stream`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['anilist', 'animeparadise'] });

const results = await sdk.search('Frieren', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);
const stream = await sdk.stream(episodes[0], { language: 'sub' });
// stream.subtitles → external VTT subtitle tracks
// stream.isHls → true (HLS master playlist)
```

## Notes

- Sub only (no dub).
- Subtitle URLs are sourced from `episode.subData` and normalized via `normalizeSubtitleEntries`.
- The HLS stream is served via `stream.animeparadise.moe/m3u8?url=...`.
