---
title: goyabu
description: Anime playback source for goyabu.io — Brazilian Portuguese dub via Google batchexecute.
---

`GoyabuSource` resolves Brazilian Portuguese (pt-br) dubbed anime from `goyabu.io`. Extracts Blogger video tokens from `playersData` on episode pages, then calls Google's `batchexecute` API to recover `googlevideo.com` MP4 URLs.

## Capabilities

- `search`, `episodes`, `stream`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['goyabu'] });

const results = await sdk.search('Naruto', { kind: 'anime' });
const { items: episodes } = await sdk.episodes(results[0]);
const stream = await sdk.stream(episodes[0]);
// stream.language → 'sub' (but the audio is Brazilian Portuguese dub)
```

## Notes

- Only source for Brazilian Portuguese content.
- If the Blogger batchexecute returns no result, the source tries to scrape direct `.m3u8` / `.mp4` URLs from the page.
- Requires the site to be reachable (`goyabu.io` can be intermittent).
