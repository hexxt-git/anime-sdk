title: mal

`MalSource` queries the public Jikan v4 API (`api.jikan.moe`) and returns `Media` records for anime and manga. No API key required.

## Capabilities

- `search(query, kind)` — full-text search
- `info(id)` — full `Media` record
- `browse({ list, kind })` — top, popular, seasonal

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['mal'] });

const results = await sdk.search('Cowboy Bebop', { kind: 'anime' });
// results[0].mappings.mal → 1

const top = await sdk.browse({ list: 'top', kind: 'anime' });
```

## ID format

MAL uses typed IDs internally (`anime:1` / `manga:13`) because the same integer can refer to both an anime and a manga. These are encoded in the opaque `id` field — you never see the typed form as a consumer.

## Browse lists

| List     | Notes                             |
| -------- | --------------------------------- |
| top      | Top anime/manga by score          |
| popular  | Top by popularity (member count)  |
| seasonal | Requires `season` + `year` params |

## Notes

- Jikan rate limit: 3 req/s, 60 req/min.
- `media.score` is computed as `Math.round(malScore * 10)` with `scale: 100`.
