title: anilist
description: AniList GraphQL catalogue source — search, info, browse.
---

`AnilistSource` queries `graphql.anilist.co` and returns `Media` records with full metadata. Enabled by default as the primary catalogue source.

## Capabilities

- `search(query, kind)` — full-text search across anime and manga
- `info(id)` — full `Media` record for a single title
- `browse({ list, kind })` — trending, popular, seasonal, top

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['anilist'] });

const results = await sdk.search('Frieren', { kind: 'anime' });
// results[0].mappings.anilist → 154587

const trending = await sdk.browse({ list: 'trending', kind: 'anime' });
const seasonal = await sdk.browse({ list: 'seasonal', kind: 'anime', season: 'FALL', year: 2024 });
```

## Browse lists

| List     | Notes                              |
| -------- | ---------------------------------- |
| trending | Currently trending on AniList      |
| popular  | All-time popularity ranking        |
| seasonal | Titles airing in `season` + `year` |
| top      | Highest-scored titles              |

## Notes

- No API key required. Public rate limit: ~90 req/min per IP.
- `media.score` is returned as `{ value, scale: 100 }` — divide by 10 to get the 0–10 rating.
- `media.mappings.mal` is populated from AniList's `idMal` field.
