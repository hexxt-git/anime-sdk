`MangapillSource` scrapes `mangapill.com`. Reliable fallback for manga not found on MangaDex.

## Capabilities

- `search`, `chapters`, `pages`

## Usage

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk({ sources: ['mangapill'] });

const results = await sdk.search('Frieren', { kind: 'manga' });
const { items: chapters } = await sdk.chapters(results[0]);
const pages = await sdk.pages(chapters[0]);
```

## Notes

- HTML scraping — may break if the site changes its layout.
- Images are in `.js-page` elements with `data-src` attributes.
- Requires `Referer: https://mangapill.com` and `User-Agent` headers.
