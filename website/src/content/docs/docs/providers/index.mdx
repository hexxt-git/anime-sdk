---
title: Sources
description: Overview of the 12 live-tested anime and manga sources in anime-sdk.
---

anime-sdk ships 12 sources divided into two categories:

- **Catalogue sources** — AniList, MAL, Kitsu. Return rich `Media` records with title, cover, score, year, and cross-catalogue ID mappings. Support `search`, `info`, and `browse`.
- **Playback sources** — site-specific adapters that resolve direct stream or image URLs. Support `episodes`/`chapters` and `stream`/`pages`.

All sources are verified on every release with live, non-mocked E2E tests.

The SDK picks the best playback source for a given title automatically, ranked by rolling success rate. You can inspect the ranking with `sdk.sources(media)` or target a specific source with `sources: ['allmanga']` in `createSdk()`.

## Catalogue sources

| ID        | Site               | Capabilities         | Notes                                                      |
| --------- | ------------------ | -------------------- | ---------------------------------------------------------- |
| `anilist` | graphql.anilist.co | search, info, browse | browse: trending, popular, seasonal, top                   |
| `mal`     | api.jikan.moe      | search, info, browse | browse: top, popular, seasonal                             |
| `kitsu`   | kitsu.io           | search, info         | surfaces cross-catalogue mappings (AniList/MAL/AniDB/TVDB) |

Catalogue sources power search and metadata. They return `Media` with `mappings.anilist`, `mappings.mal`, `mappings.kitsu` so the SDK can route to playback sources.

## Testing strategy

Each source ships with a live E2E test that:

1. Searches a real title against the live site
2. Fetches episodes or chapters
3. Resolves a stream or page URL
4. For anime: runs `ffmpeg` to extract a frame from ~5s in and asserts the PNG is > 1 KB
5. For manga: fetches the first page URL and checks the `Content-Type` is `image/*`

These tests never mock network calls. If a source's upstream site changes, the test fails loudly. Screenshots land in `scratch/screenshots/` (gitignored).

## Choosing a source

`createSdk()` picks automatically. If you want to target specific ones:

```ts
// Anime only
const sdk = createSdk({ sources: ['anilist', 'megaplay', 'allmanga'] });

// Disable one
const sdk = createSdk({ disabled: ['goyabu'] });
```

**AllManga** — widest anime catalogue, sub + dub, stable GraphQL API. Best default.

**MegaPlay** — uses AniList IDs natively so cross-source matching is instant. Sub + dub with VTT subtitles.

**AnimeParadise** — best for **external subtitle tracks** (VTT files you can pass to `<track>`).

**Anikoto** — reliable dub option, integrated subtitle tracks.

**Gogoanime** (anineko.to) — useful fallback for titles AllManga is missing.

**Goyabu** — only option for Brazilian Portuguese (pt-br dub).

**MangaDex** — gold standard for manga, huge database, clean JSON API.

**WeebCentral** and **MangaPill** — reliable fallbacks for titles not on MangaDex.
