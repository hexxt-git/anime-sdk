anime-sdk is a TypeScript SDK that searches anime and manga across 12 sources and resolves direct playable stream URLs and manga page URLs. One import, nine methods, plain POJO types.

## Requirements

- **Node 20+** or **Bun**: native `fetch` and `crypto.subtle` required
- **ffmpeg**: only needed for the live E2E test suite

## Install

```sh
npm install anime-sdk
```

## How it works

`createSdk()` returns an object with nine methods. Three calls get you a playable URL:

```ts
import { createSdk } from 'anime-sdk';

const sdk = createSdk(); // zero config — all 12 sources

// 1. Search
const results = await sdk.search('Frieren', { kind: 'anime' });

// 2. Episodes
const { items: episodes } = await sdk.episodes(results[0]);

// 3. Stream
const stream = await sdk.stream(episodes[0], { language: 'sub' });
console.log(stream.url); // playable URL
console.log(stream.origin.host); // CDN hostname
console.log(stream.adjacent.next); // next episode { id, number }
```

Manga works the same way — no language argument:

```ts
const manga = await sdk.search('Chainsaw Man', { kind: 'manga' });
const { items: chapters } = await sdk.chapters(manga[0]);
const pages = await sdk.pages(chapters[0]);
console.log(pages.pages[0].url); // image URL for page 1
```

## Value types

All return values are plain TypeScript interfaces — `JSON.stringify`-safe, safe for React state, Zustand, Redux, React Query. No classes, no `instanceof` checks.

```ts
interface Media {
  id: string; // opaque — pass back to SDK methods
  kind: 'anime' | 'manga';
  title: { preferred: string; english?: string; romaji?: string; native?: string };
  cover?: { url: string; color?: string };
  score?: { value: number; scale: number }; // { value: 87, scale: 100 } → 8.7
  year?: number;
  mappings: { anilist?: number; mal?: number; kitsu?: number };
}

interface Episode {
  id: string; // opaque
  mediaId: string;
  number: number;
  title?: string;
  languages: ('sub' | 'dub' | 'raw')[];
  qualities: ('1080p' | '720p' | '480p' | '360p' | 'auto')[];
  source: string;
}

interface Stream {
  url: string;
  origin: { host: string; url: string; proxied: boolean };
  isHls: boolean;
  qualities: { label: string; url: string }[];
  language: 'sub' | 'dub' | 'raw';
  subtitles: { url: string; language: string; label: string; format: 'vtt' | 'srt' | 'ass' }[];
  headers?: Record<string, string>;
  adjacent: {
    prev?: { id: string; number: number };
    next?: { id: string; number: number };
  };
}
```

## Browse

```ts
const trending = await sdk.browse({ list: 'trending', kind: 'anime' });
// → List<Media> = { items: Media[], nextCursor?: string }
```

Lists: `'trending'` | `'popular'` | `'seasonal'` | `'top'`. Seasonal requires `season` + `year`.

## Which source is used?

The SDK picks the best available source automatically, ranked by success rate. You don't choose — but you can inspect:

```ts
const sources = await sdk.sources(results[0]);
// → [{ id: 'megaplay', status: 'available', successRate: 0.97 }, ...]
```

To target a specific source, pass `sources: ['allmanga']` to `createSdk()`.

## Cancellation

Every method accepts `{ signal?: AbortSignal }`:

```ts
const ac = new AbortController();
setTimeout(() => ac.abort(), 5000);
const results = await sdk.search('Frieren', { kind: 'anime', signal: ac.signal });
```

## Progressive search

`sdk.search()` is both `AsyncIterable<Media>` and `PromiseLike<Media[]>`:

```ts
// Iterate as results arrive from each source:
for await (const hit of sdk.search('Frieren', { kind: 'anime' })) {
  console.log(hit.title.preferred);
}

// Or await the full array:
const all = await sdk.search('Frieren', { kind: 'anime' });
```

## Errors

```ts
import { AniError, AniErrorCode } from 'anime-sdk';

try {
  const stream = await sdk.stream(episode);
} catch (e) {
  if (e instanceof AniError) {
    switch (e.code) {
      case AniErrorCode.NoStream: // no playable URL found
      case AniErrorCode.SourceUnavailable: // upstream unreachable
      case AniErrorCode.RateLimited: // rate limit hit
      case AniErrorCode.Cancelled: // AbortSignal fired
      case AniErrorCode.NotFound: // title/episode not found
    }
  }
}
```

## HTTP server

```sh
npx anime-sdk            # → http://localhost:3030
PORT=8080 npx anime-sdk
```

Or in code:

```ts
import { startServerV2 } from 'anime-sdk/server';
await startServerV2({ port: 3030 });
```

See [HTTP Server](/docs/http-server/) for routes and configuration.

## Configuration

```ts
createSdk({
  sources?:  string[];   // whitelist source IDs; default: all 12
  disabled?: string[];   // blacklist a subset
  http?: { timeoutMs?: number; retries?: number; userAgent?: string };
  proxy?: { signSecret?: string; allowedHosts?: string[] };
  cache?: { get(k: string): unknown; set(k: string, v: unknown): void };
});
```

All fields optional. `createSdk()` with no args works out of the box.

## Downloading

```ts
import { downloadVideo, downloadMangaChapter } from 'anime-sdk';

const stream = await sdk.stream(episode, { language: 'sub' });
await downloadVideo(stream, './episode-1.mp4');

const pages = await sdk.pages(chapter);
await downloadMangaChapter(pages, './chapter-1.zip');
```
