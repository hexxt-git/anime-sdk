---
title: HTTP Server
description: Run anime-sdk as a standalone HTTP server and call it from any language over HTTP.
---

The bundled server exposes every SDK verb as an HTTP route. Zero config to start:

```sh
npx anime-sdk           # → listening on http://localhost:3030
PORT=8080 npx anime-sdk
SOURCES_DISABLED=goyabu npx anime-sdk
```

Or programmatically:

```ts
import { startServer, createSdk } from 'anime-sdk';

// Zero config — SDK auto-constructed
startServer({ port: 3030 });

// With a custom SDK instance:
startServer({
  port: 3030,
  sdk: createSdk({ sources: ['anilist', 'megaplay'] }),
});
```

`startServer` returns an `http.Server` — call `server.close()` to shut it down.

## Routes

All routes are `GET`. Errors return `{ error: string }` with the appropriate HTTP status.

### `GET /search?q=…&kind=anime`

Search for anime or manga.

| Param  | Required | Values             |
| ------ | -------- | ------------------ |
| `q`    | ✓        | search query       |
| `kind` |          | `anime` \| `manga` |

```sh
curl 'localhost:3030/search?q=Frieren&kind=anime'
```

Response: `Media[]`

```json
[
  {
    "id": "eyJ2IjoxLCJ0IjoibWVkaWEiLCJzIjoiYW5pbGlzdCIsInIiOiIxNTQ1ODcifQ",
    "kind": "anime",
    "title": {
      "preferred": "Frieren: Beyond Journey's End",
      "english": "Frieren: Beyond Journey's End"
    },
    "cover": { "url": "https://s4.anilist.co/file/anilistcdn/...", "color": "#e4a15d" },
    "score": { "value": 90, "scale": 100 },
    "year": 2023,
    "catalogues": ["anilist"],
    "playbackSources": [],
    "mappings": { "anilist": 154587, "mal": 52991 }
  }
]
```

### `GET /media/:id`

Full info for a single media record. `:id` is the opaque `id` from a search result.

```sh
curl 'localhost:3030/media/eyJ2IjoxLCJ0IjoibWVkaWEiLCJzIjoiYW5pbGlzdCIsInIiOiIxNTQ1ODcifQ'
```

Response: `Media`

### `GET /media/:id/episodes?cursor=…`

List episodes. Supports pagination via `cursor`.

```sh
curl 'localhost:3030/media/MEDIA_ID/episodes'
```

Response: `List<Episode>` — `{ items: Episode[], nextCursor?: string }`

```json
{
  "items": [
    {
      "id": "eyJ2IjoxLCJ0IjoiZXBpc29kZSIsInMiOiJtZWdhcGxheSIsInIiOiIxNTQ1ODc6MSJ9",
      "mediaId": "...",
      "number": 1,
      "title": "Episode 1",
      "languages": ["sub", "dub"],
      "qualities": ["auto"],
      "source": "megaplay"
    }
  ]
}
```

### `GET /media/:id/chapters?cursor=…`

List chapters (manga). Same shape as episodes.

### `GET /media/:id/sources`

Ranked list of playback sources available for this title.

```sh
curl 'localhost:3030/media/MEDIA_ID/sources'
```

Response: `SourceInfo[]`

```json
[
  { "id": "megaplay", "status": "available", "successRate": 0.97 },
  { "id": "allmanga", "status": "incompatible" }
]
```

### `GET /episode/:id/stream?language=sub&quality=auto&adjacency=walk-relations`

Resolve a playable stream URL.

| Param       | Values                                | Default          |
| ----------- | ------------------------------------- | ---------------- |
| `language`  | `sub` \| `dub` \| `raw`               | `sub`            |
| `quality`   | `1080p` \| `720p` \| `480p` \| `auto` | `auto`           |
| `adjacency` | `within-media` \| `walk-relations`    | `walk-relations` |

```sh
curl 'localhost:3030/episode/EPISODE_ID/stream?language=dub'
```

Response: `Stream`

```json
{
  "url": "https://cdn.example.com/ep1.m3u8",
  "origin": {
    "host": "cdn.example.com",
    "url": "https://cdn.example.com/ep1.m3u8",
    "proxied": false
  },
  "isHls": true,
  "qualities": [{ "label": "auto", "url": "https://cdn.example.com/ep1.m3u8" }],
  "language": "dub",
  "subtitles": [],
  "headers": { "Referer": "https://megaplay.buzz/" },
  "adjacent": {
    "prev": null,
    "next": { "id": "...", "number": 2 }
  }
}
```

### `GET /chapter/:id/pages`

Resolve manga page URLs.

```sh
curl 'localhost:3030/chapter/CHAPTER_ID/pages'
```

Response: `Pages`

```json
{
  "pages": [
    {
      "url": "https://uploads.mangadex.org/data/hash/page1.jpg",
      "origin": { "host": "uploads.mangadex.org" }
    }
  ],
  "adjacent": { "next": { "id": "...", "number": 2 } }
}
```

### `GET /browse?list=trending&kind=anime`

Browse a curated list.

| Param    | Values                                                     |
| -------- | ---------------------------------------------------------- |
| `list`   | `trending` \| `popular` \| `seasonal` \| `top`             |
| `kind`   | `anime` \| `manga`                                         |
| `season` | `WINTER` \| `SPRING` \| `SUMMER` \| `FALL` (seasonal only) |
| `year`   | four-digit year (seasonal only)                            |

Response: `List<Media>`

### `GET /health`

Returns current source health.

```sh
curl 'localhost:3030/health'
```

Response: `SourceHealth[]`

```json
[{ "id": "anilist", "successRate": 1, "avgLatencyMs": 320, "calls": 15 }]
```

## Calling from other languages

**Python:**

```python
import httpx

base = 'http://localhost:3030'
shows = httpx.get(f'{base}/search', params={'q': 'Frieren', 'kind': 'anime'}).json()
eps   = httpx.get(f'{base}/media/{shows[0]["id"]}/episodes').json()
data  = httpx.get(f'{base}/episode/{eps["items"][0]["id"]}/stream', params={'language': 'sub'}).json()
print(data['url'])
```

**Swift (iOS):**

```swift
let url = URL(string: "http://localhost:3030/search?q=Frieren&kind=anime")!
let (data, _) = try await URLSession.shared.data(from: url)
let shows = try JSONDecoder().decode([MediaResult].self, from: data)
```

**Kotlin / Android:**

```kotlin
val client = OkHttpClient()
val request = Request.Builder()
    .url("http://10.0.2.2:3030/search?q=Frieren&kind=anime")
    .build()
val response = client.newCall(request).execute()
```

Note: in Android emulators, `localhost` on the host machine is `10.0.2.2`.

## Error responses

| Status | Meaning                                          |
| ------ | ------------------------------------------------ |
| 400    | Missing required query parameter                 |
| 404    | Unknown route or media/episode not found         |
| 500    | Source threw an error (message in `error` field) |
